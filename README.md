# PetCat

A responsive front-end website developed to present information about cats and pet care. The project features a simple, organized interface customized with HTML and CSS.

## Demo

![PetCat demo](img/Gravação-de-Tela-2026-09-10-142633.gif)

## Features

- Home page with a featured section.
- Informative section about cats and pet care.
- Photo gallery with a zoom effect on hover.
- Google Maps integration.
- Contact form with name, email, and message fields.
- Fixed navigation menu at the top of the page.

## Technologies Used

- HTML5
- CSS3
- Flexbox
- Google Maps Embed

## CSS Features Practiced

- `hover` effects.
- Smooth transitions.
- Element shadows.
- Custom colors.
- Fixed positioning.
- Element organization with Flexbox.
- Responsive layout for different screen sizes.

## How to Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder:

   ```bash
   cd PetCat
   ```

3. Open the `index.html` file in a browser.

You can also use the Live Server extension in Visual Studio Code to preview the project during development.

## Note

The contact form is currently structured visually on the front end. To send and store messages, it must be connected to a back-end or form service.

## Project Goal

This project was developed to practice structuring web pages with HTML and creating interfaces using CSS styling features.
